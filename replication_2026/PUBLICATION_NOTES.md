# Shared research branch

Published to `RM1505/math279_project` at Brendan's request. Start with [RESOLUTION_REPORT.md](RESOLUTION_REPORT.md), the new snapshot-measurement candidate. [DECISION_REPORT.md](DECISION_REPORT.md) retains the preceding alpha-search decision. It adds the decision-stage checks and separate 2011–2016 experiment. The earlier [NEXT_DAY_REPORT.md](NEXT_DAY_REPORT.md) and [RANKING_REPORT.md](RANKING_REPORT.md) remain available. The original [REPORT.md](REPORT.md) covers the completed minute-snapshot reconstruction; its statements about no external publication refer to the earlier local run.

The branch includes source, tests, compact aggregate tables and figures. Raw books, inventories, minute caches, daily panels, fitted model objects and individual predictions remain local. Report references to these local provenance files do not mean they are bundled in this public repository.

For reproduction, use the dependency versions in the implementation manifests, create a project environment, and point `RAW` in `study.py` at the existing raw archives. Follow the extraction and analysis commands in the reports in order. Daily models require the original archive inventories and 2017–2019 caches; later daily features are rebuilt from raw 2020–2021 snapshots. Existing output files are reused, so isolate or clear stale generated outputs when changing the specification. Summary files are explicitly included despite broad ignore rules that protect against committing large outputs.

These are snapshot-data adaptations, not exact event-level OFI or trade-co-occurrence replications. No historical Sharpe claim is validated. There is no established trading strategy. The new measurement audit is a concrete research-note candidate, with novelty and publishability still provisional. Its frozen-queue control retains price changes, and its minute-sum reference is not event OFI.

# Snapshot OFI measurement study — 21 October 2026

This is a new exploratory measurement question, not another alpha search. Existing price outcomes have been examined in earlier work. Freeze the following design before computing the new contrasts.

Question: how much do temporal coarsening and shared price inputs alter an endpoint OFI proxy? Compare (A) the sum of the existing one-minute quote-transition increments across a block, (B) the single increment calculated from only that block's endpoints, and (C) an endpoint control with bid/ask queue sizes frozen at their starting values. The one-minute sum is a finer observed reference, NOT event OFI or ground truth. No inference about sub-minute loss is identified.

Use all 483 previously training-eligible stocks in the 2017–2019 minute caches. Block sizes 1, 2, 5, 10, 30 minutes; primary contrast is five minutes. Non-overlapping blocks from 10:00 through 15:55, offset zero; repeat five-minute blocks at offset two minutes as a phase sensitivity. Require every observed state in each block valid. Report excluded windows. For forward prediction additionally require the entire following block valid; do not conflate contemporaneous fit with forecasting.

Primary measurement summaries: opposite signs among both nonzero measures; endpoint zero despite nonzero minute-sum reference; correlation; normalized root mean-square discrepancy. Use a common starting visible-depth normalizer for all three measures in each block, without tanh or per-step renormalization. Reconstruct best queue sizes from cached log mean depth and queue imbalance; document float32 precision and verify against selected raw files. Exact algebra is tested to floating-point tolerance. Include a material-reference threshold |normalized minute sum|>0.1 as a stated sensitivity.

Model comparison: per stock and block scale, fit intercept/linear single-feature contemporaneous models in 2017, tune ridge strength only on 2018, refit 2017–2018, evaluate 2019. Compare minute-sum, endpoint and frozen-queue control against a training-mean benchmark. Also fit forward-next-block models with identical current return, lag return, spread, depth and endpoint queue-state controls, adding either minute-sum or endpoint pressure. All preprocessing is training-only; no next-block outcomes enter features. Include negative control of contemporaneous pressure shifted one block into the past. All contrasts are paired on identical windows.

Aggregate stocks equally within dates, then dates equally; retain annual and stock summaries. 20-day circular bootstrap with 2,000 draws; five-minute contrasts are primary, other scales/phase sensitivity descriptive. State that the nonlinear sign transform alone can produce substantial contemporaneous fit under a symmetric independent-return null; simulate it and distinguish the algebraic null from a realistic market-equilibrium model.

Deliver an exact coarsening-error decomposition, a mergeable summary that preserves summed observed increments, audited implementation/tests, empirical figures and a research note. Novelty remains provisional: explicitly compare Cont–Kukanov–Stoikov, generalized snapshot OFI, sampling/clock literature and contemporaneous-versus-predictive critiques. A high fit from the null does not refute event-level price impact or prove all real OFI information is mechanical.

Implementation clarifications (before full-universe aggregation): all *paired loss contrasts* use identical windows. The lagged-pressure model is a standalone negative control with its own eligible sample because the first block has no previous block; it is not included in paired loss tests. The measurement sample also excludes absolute within-block log returns >=0.2. Four five-minute loss contrasts (endpoint versus minute-sum explanation; frozen versus endpoint explanation; minute-sum and endpoint additions to the forward baseline) receive Holm correction as one family.

Raw-file precision audit on 18 stock-days found four exact-zero minute sums represented as tiny nonzero values after float32 queue reconstruction. Therefore retain the originally specified 1e-8 results for transparency, but add pre-aggregation sensitivities that define nonzero as exceeding 0.001, 0.01, and 0.1 starting-depth units on BOTH measures. The maximum normalized-flow error in this raw sample was 0.000122. These thresholds are robustness checks, not a universal error guarantee; emphasize material (>0.1) sign disagreements in the note. Do not claim tiny cached values establish exact nonzero flow.

Post-result extension: after the raw frozen-versus-endpoint explanatory comparison was computed, add fixed tanh(scale=1) and sign transforms of the fine and coarse measures plus sign(current return), on the primary five-minute grid. Use the same chronological fitting and report every variant for all stocks. This explicitly investigates boundedness/outlier sensitivity; it is exploratory and has no additional confirmatory p-values. The sign-return feature intentionally contains the contemporaneous target and must never be described as a forecast.

The initial code omitted the current-return screen there. Six training windows for KR on 2017-10-11 across h=1, h=2 and both h=5 grids were affected.

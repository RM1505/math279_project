# Extension protocol — 24 October 2026

Purpose: establish practical consequences, map prior overlap, and compare remedies without extending the trading-strategy search. The archive and original results are already known. All new analyses are exploratory. This document fixes the following small experiment family before its new outcomes are inspected.

1. **Selection stability:** on the 2019 five-minute grid, compare top-20 absolute minute-sum and endpoint measures across the same valid stocks at each timestamp. Report intersection/20, directional disagreement among the intersection, and rank correlation. Use top-5/top-50 only as disclosed sensitivities. Repeat using a common per-stock scale (2017 90th percentile absolute minute sum) applied to BOTH measures. Require at least 100 common valid stocks. Average timestamps within date then dates; circular 20-date bootstrap, 2,000 draws. This concerns feature-based selection, not forecast performance or portfolio returns.
2. **Endpoint reconstruction:** predict the observed five-minute minute sum, not returns, from (a) endpoint contribution alone and (b) a fixed richer endpoint feature set. Per-stock ridge penalties {0.01,1}, fit 2017, select 2018, refit through 2018, score 2019. Use training-only clipping/scaling. Rich features: C, frozen endpoint Z, start/end OBI, log-depth change, bid and ask price changes divided by starting spread, and signed and absolute C transforms. Report raw MSE against uncalibrated C and sign error on the SAME both-material F/C sample as the headline. Do not claim the richer model is an optimal decoder or that success reconstructs hidden events.
3. **Generalized OFI comparison:** implement the 2021 Su et al. arXiv construction from its equations, with explicit finite-depth censoring. Use all 105 eligible ten-level stocks and first regular available stock-day of each calendar quarter in 2019 (up to four dates per stock), chosen without looking at outcomes. Compare summed minute standard OFI, endpoint standard OFI, summed minute GOFI and endpoint GOFI on matched raw five-minute paths. Evaluate each operator's own aggregation discrepancy and, separately, GOFI versus the standard minute-sum reference. The latter is not a validity contest: the operators target different observed quantities. Do not truncate unavailable depth and pretend it is complete. Report retention, mismatch and coverage. This is a bounded diagnostic, not a full replication of the Chinese-equity price-fit study.
4. **Preservation:** harden the existing additive summary with observation-spacing metadata and normalization methods. Test mixed grids, gaps, exact shared boundaries, normalization and chunk merges. Preserve observed sums before coarsening; do not claim event recovery or novel compression theory.
5. **Prior-work and usage audit:** record sources, what is actually demonstrated, and limits of the search. Distinguish correctly summed implementations from endpoint calculations and ambiguous descriptions. Convenience examples do not estimate industry prevalence. Check the original local OFI pipeline so the new paper is not falsely used to explain old backtest weaknesses.

Stop after this specified family and a documented synthesis. A new trading sweep, claimed empirical lower bound on all endpoint estimators, or claimed universal correction would exceed the evidence. Any further analysis prompted by outcomes must be labeled post-result.

GOFI implementation clarification, before reading comparison outcomes: the 2021 equation (10) counts tick steps, while actual occupied US price levels can have gaps. Report a literal one-cent-grid version only when every required level is contiguous and covered (archive price units: 10,000 per dollar, so one cent = 100). Separately label a price-aligned adaptation that sums occupied levels through the old/new best-price boundary; it agrees with the literal construction on complete contiguous grids. Return missing when the required boundary lies beyond the visible ten levels. Neither version assumes nonexistent displayed depth is zero. Report sparse-date results descriptively without a four-date bootstrap pretending to supply reliable temporal uncertainty.

Post-result audit addition: after observing lower GOFI disagreement with substantial censoring, rerun the same four-date sample to report a second comparison requiring ALL FOUR measures to exceed 0.1. This prevents different material subsets from being mistaken for a paired improvement. Also report standard disagreement before the deep-book coverage filter. No dates or conventions are changed. These are explicitly post-result descriptive diagnostics.

# Frozen specification, before the full-study results

Scope: all available raw minute-snapshot stock archives, all full sessions in 2017–2019. Audit metadata for the complete historical archive and files throughout the original project. Rebuild inputs from raw books; do not combine old OFI caches. This is a snapshot-data adaptation, not exact replication of event-derived OFI or of the prior project's Sharpe ratios.

Eligibility uses 2017 alone: at least 70,000 valid one-minute return observations. Fit in 2017, choose ridge penalty from {0.001, 0.01, 0.1, 1} using 2018 loss, refit on 2017–2018, score 2019. These dates may have been examined in previous work; they are chronologically held out for this implementation, not guaranteed untouched research data. The archive's original stock selection is not reconstructed point-in-time, so survivorship/coverage bias remains.

All preprocessing learned in each fitting sample: feature clipping at 0.1/99.9 percentiles, centering/scaling, coefficients. Fixed tanh(flow/10) bounds raw endpoint-flow proxies before cross-sectional averaging. No PCA is needed in this simple study: deep information uses equal-weight averages across levels. Market features use the timestamp's eligible available stocks, excluding the target stock, requiring at least twenty others. Baselines include cross-stock return history so a cross-book effect must improve on cross-return information.

Baseline features: own lagged 1/5/30-minute returns, leave-own-out market returns at those horizons, spread, log top-level depth, time-of-day and its square. Book adds level-one queue imbalance and its one-minute change. Flow adds the correctly signed endpoint-flow proxy. Cross adds leave-own-out market queue/flow proxies. Deep adds mean ten-level queue and flow proxies to Flow; Deep-cross adds cross features. Zero and fitted training-label mean are explicit controls. Predictions include one intercept per model; no double-counted intercept decomposition.

Primary forecast: next one-minute log midpoint return. Secondary: five minutes and one-minute delayed entry. All labels remain within the session. Origins start at 10:00; no target reaches 16:00. Core targets end by 15:30; closing origins start at 15:30. Boundary-spanning intervals omitted. Known early-close dates and the 2018-12-05 special closure are excluded. Invalid books and non-minute grids are logged. Deep comparisons use the same stock/dates/observations; no padding one-level stocks with fake levels. Secondary fresh-quote sample excludes snapshots whose complete best quote has been unchanged for five minutes; minute data cannot establish event-level quote age.

Primary contrasts: Book−Returns, Flow−Book, Cross−Flow, Deep−Flow (deep subset only). Report squared-loss reductions and closing-minus-core differences in proportional MSE reduction (normalize each session by its comparator loss). Inference uses daily cross-section-averaged paired errors, circular blocks of twenty trading days, fixed seed, 2,000 bootstrap draws, and Holm correction across the eight primary tests (four mean improvements and four session contrasts). Additional horizons and freshness checks are exploratory. Price-return prediction is separate from profitability. Report indicative bid/ask round trips at observed quotes, not claimed achievable fills or a portfolio Sharpe. No transaction thresholds or model grids selected on 2019.

Resource limits: one process, numerical threads limited to one; one archive extracted at a time; <=400 MB uncompressed per stock extraction; compact float32 caches. Original inputs untouched. No external uploading or paid data acquisition.

Aggregation detail fixed before results: the overall primary effect gives equal weight to the core and closing session averages, then equal weight to dates and stocks within each session. Report session-specific effects alongside it. Contemporaneous diagnostic uses its own separate regression (current return on current endpoint-flow proxies); it never includes current returns as predictors. Its same chronological fitting split and matched deep subset make it a construction check only.

Session contrasts additionally require both core and closing observations for each included stock-day/horizon/sample and model pair. This ensures identical stock-day membership between the two sessions.

Metadata clarification before model evaluation: the archive also contains SPY and ten sector ETFs (XLB, XLC, XLE, XLF, XLI, XLK, XLP, XLU, XLV, XLY). Their data are audited and cached, but they are excluded from the primary stock universe and market factors to avoid silently mixing funds with individual stocks.

Secondary literature control, specified before inspection of the main effects: Baltussen, Da and Soebhag's *End-of-Day Reversal* motivates adding own-stock and leave-own-out market open-to-current returns to every forward model. Run the identical chronological fitting/scoring procedure for one-minute returns in a separate `scores_session_control` directory. This is an explicitly secondary analysis, not a change to the eight primary tests. No other models, thresholds or hyperparameter ranges are added.
